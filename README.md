# AI Product Intelligence & Shopping Assistant

## 1. Project Overview

An AI-powered product intelligence application built using Retrieval-Augmented Generation (RAG).

The system retrieves relevant product information from an Amazon product catalogue and uses a Large Language Model (LLM) to generate evidence-based answers and recommendations.

## 2. Business Problem

Customers often struggle to find suitable products, understand product specifications, compare alternatives and make informed purchasing decisions.

Traditional keyword-based search may not understand customer intent.

## 3. Project Objectives

- Build a semantic product search system.
- Implement a complete RAG pipeline.
- Retrieve relevant product information.
- Generate grounded answers using an LLM.
- Compare products based on customer requirements.
- Evaluate retrieval quality and answer accuracy.
- Develop a production-oriented application.
